Scan any AI skill before you install it

NVIDIA SkillSpector setup guide for Windows and Mac

Free skills arrive by DM and links every day, and many are genuinely useful. But a skill is not just a prompt: it can run code on your laptop, the same laptop that has your client files and saved passwords. SkillSpector is a free, open-source scanner from NVIDIA that checks a skill before you install it. Setup takes about 10 minutes, one time.

Why bother?In a study of 31,132 skills from public marketplaces, 26.1% had at least one vulnerability, and skills with executable scripts were 2.12 times more likely to be vulnerable (Liu et al., 2026, cited in the SkillSpector README).

The 3 checks I do before installing any skill

1

Read the SKILL.md file

Open it and read it. Does it ask for passwords, API keys or access it doesn't need for its job? Delete it.

2

Scan it with SkillSpector

Paste the GitHub link and get a risk score out of 100. Above 50? Don't install it.

3

Has a script? Test it in an empty folder first

Try it in a fresh folder with nothing important in it before you use it on real work.

The rest of this page sets up check 2.

Part A: One-time setup (about 10 minutes)

1

Open the terminal

Windows: press the Start button, type PowerShell and open Windows PowerShell (no need for "Run as administrator").

Mac: press Cmd + Space, type Terminal and press Enter.

Every command below goes into this window. Copy it with the Copy button, paste it, and press Enter.

2

Install Git

SkillSpector is installed straight from its GitHub page, so your computer needs Git. Check first:

git --version

If you see a version number (like git version 2.x), skip to step 3. If not:

Windows

winget install --id Git.Git -e

If winget isn't found, download the installer from git-scm.com/downloads and click Next through it.

Mac

xcode-select --install

Click Install in the window that opens. When it finishes, close the terminal and open it again.

3

Install uv (a free Python tool installer)

uv installs SkillSpector and downloads the right Python version for it by itself, so you don't need to install Python separately.

Windows (PowerShell)

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Mac (Terminal)

curl -LsSf https://astral.sh/uv/install.sh | sh

Close the terminal and open it again, then check:

uv --version
4

Install SkillSpector

Same command on Windows and Mac. It takes a minute or two the first time.

uv tool install --python 3.13 git+https://github.com/NVIDIA/skillspector.git

If the next step says "skillspector is not recognized" or "command not found", run this, then close and reopen the terminal:

uv tool update-shell
5

Check it works

skillspector scan --help

You should see a list of options such as --format and --no-llm. Setup is done.

Part B: Scan a skill (every time, 1 minute)

6

Scan it

Skill on GitHub: copy the link of the skill's GitHub page from your browser and put it in place of the example link:

skillspector scan https://github.com/OWNER/SKILL-NAME --no-llm

Skill you downloaded as a .zip:

Windows

skillspector scan "$HOME\Downloads\skill-name.zip" --no-llm

Mac

skillspector scan ~/Downloads/skill-name.zip --no-llm

You can also scan an unzipped folder or a single SKILL.md file the same way: put its path after scan, in quotes if it has spaces.

Why --no-llm?It keeps the skill's files on your computer and needs no API key. Without it, SkillSpector also sends the files to an AI model for a deeper check, which needs an API key (see "Extras" below).
7

Read the result

At the end you'll see a Score out of 100, a Severity and a Recommendation, followed by each finding with what it is and which file and line it's in.

ScoreSeverityWhat to do
0 to 20LOW · SAFEOK to install. Still do check 1 (read SKILL.md).
21 to 50MEDIUM · CAUTIONRead every finding. Install only if you understand each one and it makes sense for what the skill does.
51 to 80HIGHDon't install.
81 to 100CRITICALDon't install.

Score bands and recommendations are from the SkillSpector README.

8

Skill has scripts? Test it in an empty folder

  1. Make a new, empty folder, for example skill-test on your Desktop. Keep client files, passwords and .env files out of it.
  2. Install the skill only for that folder. In Claude Code that means putting it in skill-test/.claude/skills/, not in your personal skills folder.
  3. Open your AI tool in that folder, run the skill once, and watch what it asks to do: files it wants to read, commands it wants to run, websites it wants to reach.
  4. Only if everything looks right, install it where you do real work.

Extras (optional)

Update SkillSpector later 
uv tool upgrade skillspector
Deeper AI check (needs an API key)

Run the scan without --no-llm and SkillSpector adds an AI review on top of its built-in checks. It uses NVIDIA's model service by default, which needs an NVIDIA_INFERENCE_KEY; other providers (OpenAI, Anthropic, a local Ollama model) are also supported. This sends the skill's file contents to that provider. Setup details are in the SkillSpector README.

Use it from inside Claude Code (advanced)

Install the version with the MCP extra, then add it to Claude Code:

uv tool install --python 3.13 --force "skillspector[mcp] @ git+https://github.com/NVIDIA/skillspector.git"
claude mcp add skillspector -- skillspector mcp

Then you can ask Claude Code to "scan this skill with SkillSpector" before installing it.

Good to know

A low score is not a guarantee.SkillSpector never runs the skill; it reads the files and flags risky patterns. It doesn't protect you if you install a risky skill anyway, and it can miss tricks hidden in images, encrypted or compiled code, and text in languages other than English (so a skill written in Malayalam deserves an extra careful read). Keep doing checks 1 and 3.
  • Even with --no-llm, SkillSpector looks up the skill's dependency names (not your files) in the public OSV.dev vulnerability database.
  • On Windows, saving the report to a file with --output isn't supported. Read the result in the terminal.

If something goes wrong

ProblemFix
"skillspector is not recognized" / "command not found"Run uv tool update-shell, then close and reopen the terminal.
"git" not found during step 4Do step 2, then close and reopen the terminal and run step 4 again.
"uv" not found after step 3Close and reopen the terminal. On Windows, open a new PowerShell window.
Scan stops with an error about the sourceCheck the link is the skill's GitHub page and the file path is correct and in quotes.

ഏത് AI skill-ഉം install ചെയ്യുന്നതിന് മുൻപ് scan ചെയ്യൂ

NVIDIA SkillSpector setup guide · Windows, Mac

DM-ലോ link ആയോ ദിവസവും free skills കിട്ടും. പലതും ശരിക്കും ഉപകാരമുള്ളതാണ്. പക്ഷേ ഒരു skill വെറും prompt അല്ല. അതിന് നിങ്ങളുടെ laptop-ൽ code run ചെയ്യാൻ പറ്റും, client files-ഉം saved passwords-ഉം ഉള്ള അതേ laptop-ൽ. NVIDIA ഉണ്ടാക്കിയ സൗജന്യ, open-source scanner ആണ് SkillSpector. Skill install ചെയ്യുന്നതിന് മുൻപ് അത് check ചെയ്യും. Setup ഒരു തവണ മാത്രം, ഏകദേശം 10 മിനിറ്റ്.

എന്തിന് check ചെയ്യണം?Public marketplaces-ലെ 31,132 skills പഠിച്ചപ്പോൾ 26.1%-ൽ കുറഞ്ഞത് ഒരു vulnerability എങ്കിലും ഉണ്ടായിരുന്നു. Executable scripts ഉള്ള skills-ന് vulnerable ആകാനുള്ള സാധ്യത 2.12 മടങ്ങ് കൂടുതലാണ് (Liu et al., 2026; SkillSpector README-ൽ കൊടുത്തിരിക്കുന്ന പഠനം).

ഏത് skill install ചെയ്യുന്നതിന് മുൻപും ഞാൻ ചെയ്യുന്ന 3 checks

1

SKILL.md file വായിക്കൂ

File തുറന്ന് വായിക്കുക. ആ ജോലിക്ക് ആവശ്യമില്ലാത്ത password-ഓ API key-യോ access-ഓ ചോദിക്കുന്നുണ്ടോ? Delete ചെയ്യൂ.

2

SkillSpector-ൽ scan ചെയ്യൂ

GitHub link paste ചെയ്താൽ നൂറിൽ ഒരു risk score കിട്ടും. അമ്പതിന് മുകളിലാണോ? Install ചെയ്യരുത്.

3

Script ഉണ്ടോ? ആദ്യം ഒരു empty folder-ൽ test ചെയ്യൂ

പ്രധാനപ്പെട്ട ഒന്നുമില്ലാത്ത ഒരു പുതിയ folder-ൽ ആദ്യം try ചെയ്യുക. അതിനുശേഷം മാത്രം യഥാർത്ഥ ജോലിയിൽ ഉപയോഗിക്കുക.

ഇനിയുള്ള steps check 2 set up ചെയ്യാനുള്ളതാണ്.

Part A: ഒറ്റത്തവണ setup (ഏകദേശം 10 മിനിറ്റ്)

1

Terminal തുറക്കുക

Windows: Start button അമർത്തി PowerShell എന്ന് type ചെയ്ത് Windows PowerShell തുറക്കുക ("Run as administrator" വേണ്ട).

Mac: Cmd + Space അമർത്തി Terminal എന്ന് type ചെയ്ത് Enter അമർത്തുക.

താഴെയുള്ള എല്ലാ commands-ഉം ഈ window-ൽ ആണ് type ചെയ്യേണ്ടത്. Copy button അമർത്തി copy ചെയ്യുക, paste ചെയ്യുക, പിന്നെ Enter അമർത്തുക.

2

Git install ചെയ്യുക

SkillSpector അതിന്റെ GitHub page-ൽ നിന്ന് നേരിട്ടാണ് install ചെയ്യുന്നത്. അതിന് computer-ൽ Git വേണം. ആദ്യം check ചെയ്യുക:

git --version

ഒരു version number കണ്ടാൽ (ഉദാ: git version 2.x) step 3-ലേക്ക് പോകാം. ഇല്ലെങ്കിൽ:

Windows

winget install --id Git.Git -e

winget കിട്ടുന്നില്ലെങ്കിൽ git-scm.com/downloads-ൽ നിന്ന് installer download ചെയ്ത് Next അമർത്തി install ചെയ്യുക.

Mac

xcode-select --install

തുറന്നുവരുന്ന window-ൽ Install അമർത്തുക. കഴിഞ്ഞാൽ terminal close ചെയ്ത് വീണ്ടും തുറക്കുക.

3

uv install ചെയ്യുക (സൗജന്യ Python tool installer)

uv ആണ് SkillSpector install ചെയ്യുന്നത്. അതിനുവേണ്ട Python version-ഉം uv തന്നെ download ചെയ്യും. Python വേറെ install ചെയ്യേണ്ട.

Windows (PowerShell)

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Mac (Terminal)

curl -LsSf https://astral.sh/uv/install.sh | sh

Terminal close ചെയ്ത് വീണ്ടും തുറക്കുക, എന്നിട്ട് check ചെയ്യുക:

uv --version
4

SkillSpector install ചെയ്യുക

Windows-ലും Mac-ലും ഒരേ command. ആദ്യത്തെ തവണ ഒന്നോ രണ്ടോ മിനിറ്റ് എടുക്കും.

uv tool install --python 3.13 git+https://github.com/NVIDIA/skillspector.git

അടുത്ത step-ൽ "skillspector is not recognized" എന്നോ "command not found" എന്നോ വന്നാൽ ഇത് run ചെയ്യുക, എന്നിട്ട് terminal close ചെയ്ത് വീണ്ടും തുറക്കുക:

uv tool update-shell
5

ശരിയായി install ആയോ എന്ന് check ചെയ്യുക

skillspector scan --help

--format, --no-llm പോലുള്ള options-ന്റെ ഒരു list കാണും. Setup കഴിഞ്ഞു.

Part B: Skill scan ചെയ്യാം (ഓരോ തവണയും, 1 മിനിറ്റ്)

6

Scan ചെയ്യുക

Skill GitHub-ൽ ആണെങ്കിൽ: browser-ൽ നിന്ന് skill-ന്റെ GitHub page link copy ചെയ്ത്, താഴെയുള്ള example link-ന് പകരം കൊടുക്കുക:

skillspector scan https://github.com/OWNER/SKILL-NAME --no-llm

.zip ആയി download ചെയ്ത skill ആണെങ്കിൽ:

Windows

skillspector scan "$HOME\Downloads\skill-name.zip" --no-llm

Mac

skillspector scan ~/Downloads/skill-name.zip --no-llm

Unzip ചെയ്ത folder-ഓ ഒരു SKILL.md file മാത്രമോ ഇതുപോലെ scan ചെയ്യാം: scan കഴിഞ്ഞ് അതിന്റെ path കൊടുക്കുക. Path-ൽ space ഉണ്ടെങ്കിൽ quotes-നുള്ളിൽ കൊടുക്കുക.

--no-llm എന്തിന്?Skill-ന്റെ files നിങ്ങളുടെ computer-ൽ തന്നെ നിൽക്കും, API key-യും വേണ്ട. ഇത് ഇല്ലാതെ run ചെയ്താൽ, കൂടുതൽ ആഴത്തിലുള്ള check-നായി SkillSpector files ഒരു AI model-ന് അയയ്ക്കും. അതിന് API key വേണം (താഴെ "Extras" നോക്കുക).
7

Result വായിക്കുക

അവസാനം Score (100-ൽ), Severity, Recommendation എന്നിവ കാണും. അതിനു താഴെ ഓരോ finding-ഉം, അത് എന്താണെന്നും ഏത് file-ൽ, ഏത് line-ൽ ആണെന്നും കാണിക്കും.

ScoreSeverityഎന്ത് ചെയ്യണം
0 മുതൽ 20LOW · SAFEInstall ചെയ്യാം. എന്നാലും check 1 (SKILL.md വായിക്കൽ) ചെയ്യുക.
21 മുതൽ 50MEDIUM · CAUTIONഓരോ finding-ഉം വായിക്കുക. ഓരോന്നും മനസ്സിലായി, skill ചെയ്യുന്ന ജോലിക്ക് അത് ആവശ്യമാണെങ്കിൽ മാത്രം install ചെയ്യുക.
51 മുതൽ 80HIGHInstall ചെയ്യരുത്.
81 മുതൽ 100CRITICALInstall ചെയ്യരുത്.

Score ranges-ഉം recommendations-ഉം SkillSpector README-ൽ നിന്നുള്ളതാണ്.

8

Skill-ൽ scripts ഉണ്ടോ? ഒരു empty folder-ൽ test ചെയ്യുക

  1. ഒരു പുതിയ, ഒഴിഞ്ഞ folder ഉണ്ടാക്കുക. ഉദാ: Desktop-ൽ skill-test. Client files, passwords, .env files ഒന്നും അതിൽ വയ്ക്കരുത്.
  2. Skill ആ folder-ന് മാത്രമായി install ചെയ്യുക. Claude Code-ൽ ആണെങ്കിൽ skill-test/.claude/skills/-ൽ വയ്ക്കുക, നിങ്ങളുടെ personal skills folder-ൽ അല്ല.
  3. ആ folder-ൽ AI tool തുറന്ന് skill ഒരു തവണ run ചെയ്യുക. അത് എന്തൊക്കെ ചെയ്യാൻ ചോദിക്കുന്നു എന്ന് ശ്രദ്ധിക്കുക: ഏത് files വായിക്കാൻ, ഏത് commands run ചെയ്യാൻ, ഏത് websites-ലേക്ക് connect ചെയ്യാൻ.
  4. എല്ലാം ശരിയാണെന്ന് തോന്നിയാൽ മാത്രം യഥാർത്ഥ ജോലി ചെയ്യുന്നിടത്ത് install ചെയ്യുക.

Extras (വേണമെങ്കിൽ മാത്രം)

പിന്നീട് SkillSpector update ചെയ്യാൻ 
uv tool upgrade skillspector
കൂടുതൽ ആഴത്തിലുള്ള AI check (API key വേണം)

--no-llm ഇല്ലാതെ scan run ചെയ്താൽ, built-in checks-ന് പുറമേ ഒരു AI review-ഉം SkillSpector ചെയ്യും. Default ആയി NVIDIA-യുടെ model service ആണ് ഉപയോഗിക്കുന്നത്. അതിന് NVIDIA_INFERENCE_KEY വേണം. OpenAI, Anthropic, local Ollama model പോലുള്ള മറ്റ് providers-ഉം ഉപയോഗിക്കാം. ഇങ്ങനെ ചെയ്യുമ്പോൾ skill-ന്റെ file contents ആ provider-ന് അയയ്ക്കും. Setup വിവരങ്ങൾ SkillSpector README-ൽ ഉണ്ട്.

Claude Code-നുള്ളിൽ നിന്ന് ഉപയോഗിക്കാൻ (advanced)

MCP extra ഉള്ള version install ചെയ്യുക, എന്നിട്ട് Claude Code-ൽ add ചെയ്യുക:

uv tool install --python 3.13 --force "skillspector[mcp] @ git+https://github.com/NVIDIA/skillspector.git"
claude mcp add skillspector -- skillspector mcp

ഇനി ഒരു skill install ചെയ്യുന്നതിന് മുൻപ് Claude Code-നോട് "scan this skill with SkillSpector" എന്ന് പറഞ്ഞാൽ മതി.

അറിഞ്ഞിരിക്കേണ്ടത്

Score കുറവാണെന്നത് ഒരു guarantee അല്ല.SkillSpector skill run ചെയ്യുന്നില്ല. Files വായിച്ച് അപകടസാധ്യതയുള്ള patterns കണ്ടെത്തുക മാത്രമാണ് ചെയ്യുന്നത്. Risk ഉള്ള skill നിങ്ങൾ install ചെയ്താൽ അത് നിങ്ങളെ സംരക്ഷിക്കില്ല. Images-ലോ encrypted / compiled code-ലോ ഒളിപ്പിച്ച കാര്യങ്ങളും, English അല്ലാത്ത ഭാഷകളിലെ text-ഉം അത് miss ചെയ്യാം. അതുകൊണ്ട് Malayalam-ൽ എഴുതിയ ഒരു skill കൂടുതൽ ശ്രദ്ധിച്ച് വായിക്കണം. Check 1-ഉം 3-ഉം തുടർന്നും ചെയ്യുക.
  • --no-llm ഉപയോഗിച്ചാലും, skill-ന്റെ dependency names (നിങ്ങളുടെ files അല്ല) public OSV.dev vulnerability database-ൽ SkillSpector check ചെയ്യും.
