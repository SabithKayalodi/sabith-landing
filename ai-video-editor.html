Build your own AI video editor with Claude Code

Voice + photo in. Finished Reel out.

I didn't edit my last reel, not a single second. I gave Claude Code one voice file and one photo, and it did the cuts, captions, motion graphics and music. Here is the whole setup: 5 steps, 5 free tools, 3 copy-paste prompts and 2 free skills. You don't install anything by hand. Claude does it for you.

Before you start

  • The Claude desktop app, with Claude Code opened inside it. Use the desktop app, not the browser.
  • A Claude plan that includes Claude Code (it may need a paid plan).
  • Node.js 22 or newer, which HyperFrames needs. If you don't have it, Claude can install it in step 3.
  • Links to 3 to 5 Instagram videos whose editing style you like, for step 4.
  • A voiceover (your own recording or an AI voice) and one photo of you, for step 5. The script text helps too.
1

Install Claude and open Claude Code

  1. Install the Claude desktop app from claude.ai/download and sign in.
  2. Open the Code tab. That's Claude Code.
2

Set up your workspace

  1. On your computer, create a folder called AI Video Editor.
  2. Inside it, create three folders: Raw Footage, References and Exports.
  3. In Claude Code, start a new chat, choose Local, then select the AI Video Editor folder. Now Claude can see your files.
AI Video Editor ├─ Raw Footage your voice, photo, clips ├─ References style videos └─ Exports finished videos
3

Install the tools (prompt 1)

Paste this into Claude Code. Claude installs and tests all five tools. When it asks for permission to run a command, read it and allow it. Wait until it says it's ready.

I want you to be my video editor. Install these tools on my computer and test each one:
1. Remotion: github.com/remotion-dev/remotion
2. HyperFrames: github.com/heygen-com/hyperframes
3. FFmpeg: github.com/FFmpeg/FFmpeg
4. Whisper (whisper.cpp): github.com/ggml-org/whisper.cpp
5. yt-dlp: github.com/yt-dlp/yt-dlp
When everything works, tell me you are ready.
ToolWhat it does
RemotionBuilds videos from code: motion graphics and edits
HyperFramesHeyGen's open-source tool that turns HTML into MP4, also for motion graphics
FFmpegCuts, mixes and exports video and audio
WhisperTurns speech into timed text, so Claude can make captions
yt-dlpDownloads your reference videos
4

Teach Claude your style (prompt 2)

Claude knows how to edit, but it doesn't know your taste. Replace the three placeholders with links to videos whose editing you like (3 to 5 is best), then paste the prompt. Claude builds a brand sheet for you to review.

Learn the editing style from these videos:
[PASTE INSTAGRAM LINK 1]
[PASTE INSTAGRAM LINK 2]
[PASTE INSTAGRAM LINK 3]
1. Download each one into my References folder.
2. Study what they have in common: fonts, colors, caption style, cuts, zooms, pacing, motion graphics, music, and sound.
3. Build me a brand sheet that I can review. Make it inspired by these videos, not a copy of them.
Once I approve it, follow it every time you edit for me.
The most important line"Make it inspired by these videos, not a copy of them." That is what makes your edits look like yours. Read the brand sheet before you approve it.
5

Voice + photo → Reel (prompt 3)

No camera needed. Put your voice file and one photo in the Raw Footage folder (add the script as a .txt file if you have it). Install the free faceless-reel skill once, then paste this prompt and fill in the file names and your handle.

Make an Instagram Reel from my voiceover, using the faceless-reel skill:
Voice: [VOICE FILE] in my Raw Footage folder
Photo: [PHOTO FILE] in my Raw Footage folder
Script: [SCRIPT FILE, or delete this line]
1. Follow my approved brand sheet.
2. Time every scene and caption to my voice.
3. Show my photo as a small round badge with my handle [@YOUR HANDLE].
4. Add motion graphics, music, and sound effects.
Show me a preview screenshot of every scene first. After I approve, export the final video to my Exports folder.

Claude times every scene to your voice, adds captions, motion graphics and music, and shows you preview screenshots first. Approve them and the finished video lands in Exports.

Not happy with something? Just tell Claude in plain words, like you'd tell a person: "Make the hook bigger." or "Change the background." Claude fixes it.

Filming yourself instead? Use this prompt

Put your raw video in Raw Footage and replace [FILE NAME].

Edit my new video into an Instagram Reel:
[FILE NAME] in my Raw Footage folder
1. Remove every pause longer than 0.1 seconds.
2. Follow my approved brand sheet.
3. Add captions, music, and motion graphics.
4. Use anything useful from my References folder.
Show me a storyboard to review first. After I approve it, export the final video to my Exports folder.

Free skills

A skill is a set of instructions Claude follows every time it does a certain job. These two are the ones behind my reels, cleaned up so they work for anyone.

faceless-reel

Turns your voice + photo into a finished Reel in your brand style: scenes timed to your voice, word-by-word captions, your photo badge, motion graphics, music and sound effects. Shows you screenshots before it renders.

Download faceless-reel
reel-post-kit

Gets a finished Reel ready to post: a cover thumbnail in your style, 3 caption options and the comment-keyword auto-DM.

Download reel-post-kit

Install a skill: download the .zip, then paste this into Claude Code (with your AI Video Editor folder open) and fill in the file name.

Install the skill in [ZIP FILE NAME] from my Downloads folder into this project's .claude/skills folder, then tell me it's ready.
Check before you installOpen the SKILL.md file and read it, or scan it first, even when it's from me. Here's how to scan a skill.

Tips for better results

  • Pick 3 to 5 reference videos that share the same style.
  • Give Claude your script text. Captions then use your exact words and spellings.
  • Review the brand sheet and the preview screenshots before you approve them.
  • Ask for one change at a time, in plain words.
  • Only use music you're allowed to use (royalty-free or your own licence).

If something goes wrong

ProblemFix
Claude can't see your filesStart a new Claude Code chat, choose Local, and select the AI Video Editor folder itself, not a folder inside it.
A tool fails to installPaste the error back into the chat and say "fix this". If it mentions Node.js, ask Claude to install Node.js 22 first.
Captions spell your words wrongPut your script in Raw Footage as a .txt file and name it in prompt 3. For Malayalam and other languages, ask Claude to use the large Whisper model.
Reference video won't downloadCheck the link opens in your browser. Private accounts can't be downloaded; pick a public video.
The edit doesn't feel like youAsk Claude to update the brand sheet with one specific change, approve it, then edit again.
